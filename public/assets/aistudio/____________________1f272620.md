## 1. 文档概述
### 1.1 文档目的
本文档旨在全面定义生产制造执行系统（MES/ERP）中**外协加工单管理**模块的产品需求，涵盖**外协申请单**与**外协工单**两大核心单据的业务流程、两个页面之间的流转关系、页面布局、每个字段的数据来源与计算规则、联动逻辑、弹窗交互及状态流转，作为研发、测试、产品及业务团队的统一实现标准。

### 1.2 业务背景与定位
在生产制造过程中，企业由于产能限制、特殊工艺要求或成本优化考量，需要将部分工序（**工序外协**）或整个产品（**整单外协**）委托外部供应商加工：

+ **外协申请单**：由生产计划或车间人员发起，明确外协类型（工序外协/整单外协）、外协方式（包工包料/包工不包料）、需求日期及待外协的产品/物料清单（支持多销售订单项次），经内部审批通过后作为下游外协执行依据。
+ **外协工单**：系统进入时的**默认打开页面**。采购或外协跟单人员可基于已审批的**外协申请单**（或在不选择外协申请单时直接关联销售订单/物料）创建正式外协加工单，落实外协供应商、加工单价、税率、优惠率、定金金额及计划交期，并跟踪后续**外协报工（支持电脑端/手机端报工链接协同）**、**外协入库**及**费用明细核算**全流程。

## 2. 核心业务概念与全局规则
### 2.1 外协类型区分规则（核心联动）
系统支持两种外协类型：**工序外协**与**整单外协**。不同外协类型直接决定单据基本信息字段、物料清单/生产明细列结构、导入按钮及弹窗内容、以及是否展示BOM明细：

| 维度 | 工序外协 | 整单外协 |
| :--- | :--- | :--- |
| **业务定义** | 仅将生产工艺路线中的特定一道或多道工序委托外部供应商加工 | 将整个成品/半成品完整委托外部供应商生产加工 |
| **基本信息附加字段** | 必填展示 **工艺路线**（单选）、**工序**（多选，根据所选工艺路线联动带出） | 隐藏 **工艺路线**、**工序** 字段 |
| **操作按钮与导入方式** | 支持 **从销售订单导入**（统一命名）、**从物料导入** | 仅支持 **从销售订单导入**（不展示从物料导入） |
| **从销售订单导入弹窗** | 展示产品信息 + 物料信息（含物料编码、物料名称、物料分类、物料规格）；单位与数量指代**物料**的单位与数量；**弹窗底部支持分页**（展示已选条数、总条数、每页条数切换、页码跳转） | **不展示**物料编码、物料名称、物料分类、物料规格；单位定义为**产品的单位**，数量定义为**产品的数量**；**弹窗底部支持分页** |
| **物料清单 / 生产明细表** | 包含物料编码、物料名称、物料分类、物料规格列；单位与数量为**物料**的单位与数量 | **隐藏**物料编码、物料名称、物料分类、物料规格列；单位与数量为**产品**的单位与数量 |
| **BOM明细模块** | 不展示 BOM 明细 | 在物料清单/生产明细下方展示 **BOM明细**（外协工单BOM明细在物料编码左侧新增字段：**销售订单、项次、产品编码、产品名称、产品规格**），点击上方明细行可切换查看/维护对应产品的子项 BOM，支持分页 |

### 2.2 外协方式定义
+ **包工包料**：由外协供应商自行采购全部或主要原辅料并完成加工。
+ **包工不包料**：由本企业提供原辅料（按 BOM 投料发料），外协供应商仅负责加工并收取加工费。

### 2.3 跨单据全局规则与通用交互规范
1. **系统默认首页**：系统打开后默认进入 **「外协工单」** 页面。
2. **移除优先级**：外协申请单与外协工单的新增/编辑页、详情页、列表页均**不包含「优先级」**字段。
3. **列表多销售订单项次与多物料展示、列宽调整与悬浮提示**：
   - 外协工单和外协申请单均存在物料或产品对应**多个销售订单项次**的情况，列表页统一增加 **「销售订单」** 列（支持多个销售订单及项次聚合展示，格式如：`HY-26C-081 第3项、HY-26C-080 第1,2项`）。
   - 列表页原「产品信息」字段统一改名为 **「物料信息」** 四个字，支持多个产品/物料聚合展示（如：`换边机、0.5米双轨接驳台 2台`）。
   - 列表页及选择弹窗均支持**鼠标拖拽表头分隔线调整列宽**；当展示内容超过列宽时，超出部分用**省略号 (`...`)** 展示，**鼠标悬浮在超出的字段上弹出浮层展示全部信息**。
4. **详情页与新增页统一布局**：
   - 外协申请单和外协工单的详情页统一采用与新增页面一致的 **「左侧页签锚点定位 + 右侧滚动」** 布局，点击左侧页签平滑滚动定位至右侧对应模块，右侧滚动时自动同步高亮左侧页签。

### 2.4 外协申请单与外协工单两个页面之间的流程
外协工单既支持**关联外协申请单创建（受控流转）**，也支持**不选外协申请单直接创建（敏捷流转）**：

```plain
┌────────────────────────┐
│      销售订单管理      │ (数据源：销售订单号、项次、产品编码/名称/分类/规格、BOM版本、子件物料)
└───────────┬────────────┘
            │
            ├────────────────────────────────────────────────┐
            ▼ 路径一：先发起外协申请单                         ▼ 路径二：不选申请单，直接建外协工单
┌────────────────────────┐                       ┌────────────────────────┐
│   1. 外协申请单页面    │                       │    2. 外协工单页面     │
│ • 从销售订单导入明细   │                       │ • 外协申请单置空(非必填)│
│ • 状态：草稿→待审核    │                       │ • 自主选择：外协类型、 │
│   →进行中              │                       │   工艺路线、工序、     │
└───────────┬────────────┘                       │   需求日期             │
            │                                    │ • 从销售订单导入明细   │
            ├─ 方式A：在申请单列表/详情点击「转外协工单」       └───────────┬────────────┘
            └─ 方式B：在新建外协工单点击「外协申请单」弹窗选择              │
            │                                                │
            ▼                                                ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                     外协工单（新建 / 编辑 / 详情）                      │
│ • 当选择了「外协申请单」时：自动带出申请单的【外协类型、工艺路线、工序、 │
│   需求日期】且全部锁定为无法选择，同时自动带出申请单的物料/产品明细。   │
│ • 工单生效后 → 回写外协申请单的「已转外协数量」及明细行「已转数/未转数」 │
│ • 供应商通过「报工链接」提报生产进度（100%后转待入库）→ 入库完成后完结  │
└─────────────────────────────────────────────────────────────────────────┘
```

## 3. 模块一：外协申请单（Outsourcing Application）
### 3.1 功能架构
1. **外协申请单列表页**：多状态页签筛选、多条件组合查询、可拖拽列宽与超出省略悬浮提示、自定义列配置与表头筛选排序、快捷流转操作。
2. **新增/编辑外协申请单**：左侧步骤锚点导航 + 右侧滚动表单（基本信息、物料清单、整单外协专属 BOM 明细）。
3. **外协申请单详情页**：与新增页一致的左侧页签锚点定位 + 右侧滚动展示（基本信息、物料清单、关联外协工单记录）。

---

### 3.2 外协申请单列表页
#### 3.2.1 状态页签（Tabs）
顶部提供状态快速切换及对应单据数量角标：

+ `全部`、`草稿`、`待审核`、`进行中`、`审批驳回`、`已完成`、`已取消`、`待反审批`

#### 3.2.2 筛选查询区
+ **关键词搜索**：申请单号、关联销售订单号、产品/物料名称或编码、申请人。
+ **下拉筛选**：
    - 外协类型：`全部` / `工序外协` / `整单外协`
    - 外协方式：`全部` / `包工包料` / `包工不包料`
+ **日期区间**：申请日期（开始日期 ~ 结束日期）。

#### 3.2.3 列表字段定义与数据来源
支持**拖拽调整列宽**、超出列宽用**省略号**展示、**鼠标悬浮超出的字段展示全部信息**，支持单列筛选排序：

| 序号 | 字段名称 | 字段说明 | 数据来源与计算规则 |
| :--- | :--- | :--- | :--- |
| 1 | 序号 | 列表行序号 | 当前页列表自增序号 `1, 2, 3...` |
| 2 | 申请单编号 | 系统唯一编号（如 `HYCG-202610280001`），点击进入详情页 | 新增时系统按日期流水自动生成 |
| 3 | **销售订单** | 展示关联的多个销售订单号及项次 | **聚合计算**：汇总单据物料清单中的销售订单号（`source`）与项次（`lineNo`），格式如 `HY-26C-081 第3项、HY-26C-080 第1,2项` |
| 4 | **物料信息** | 展示多个物料或产品名称及数量（原“产品信息”改为**物料信息**四个字） | **聚合计算**：工序外协汇总明细中的 `物料名称 + 数量 + 单位`；整单外协汇总明细中的 `产品名称 + 数量 + 单位`，多项用 `、` 分隔 |
| 5 | 外协类型 | `工序外协` / `整单外协` | 取自单据主表 `outsourcingType` 字段 |
| 6 | 外协方式 | `包工包料` / `包工不包料` | 取自单据主表 `outsourcingMethod` 字段 |
| 7 | 申请日期 | 单据发起日期 | 取自单据主表 `applyDate`（新增时默认当天日期） |
| 8 | 总数量 | 明细行申请数量合计 | **自动汇总**：当前申请单下所有明细行的 `申请数量 (requestQty)` 之和 |
| 9 | 已转外协数量 | 已下推生成外协工单的数量合计 | **下游回写**：汇总所有关联该申请单的有效外协工单计划数量之和 |
| 10 | 需求日期 | 期望外协加工完成的交付日期 | 取自单据主表用户录入的 `requiredDate` |
| 11 | 备注 | 申请备注说明 | 取自单据主表 `remark` 字段 |
| 12 | 所属公司 | 归属组织/法人实体 | 默认取当前登录租户公司名称（如 `智简工厂测试租户`） |
| 13 | 状态 | 状态标签（草稿、待审核、进行中、已完成、审批驳回、已取消、待反审批） | 由单据审批与下游转单状态机驱动流转 |
| 14 | 操作 | 根据状态动态展示：`详情`、`编辑`、`提交审批`、`审核`、`转外协`、`反审批`、`删除` | 根据当前行 `状态` 权限矩阵动态渲染 |

### 3.3 新增 / 编辑外协申请单
页面采用**左侧步骤锚点导航 + 右侧卡片区块滚动布局**（包含 `1. 基本信息`、`2. 物料清单` 及整单外协下的 `BOM明细`）。

#### 3.3.1 基本信息字段定义与数据来源
| 字段名称 | 控件类型 | 必填 | 数据来源与校验业务规则 |
| :--- | :--- | :--- | :--- |
| **申请单号** | 文本输入框 | 是 | **数据来源**：系统自动生成唯一流水号（如 `HYCG-202610280001`） |
| **外协类型** | 单选框/下拉框 | 是 | **数据来源**：系统枚举（`工序外协`、`整单外协`，默认 `工序外协`）。切换时联动更新下方工艺路线/工序字段与物料清单结构 |
| **外协方式** | 单选框/下拉框 | 是 | **数据来源**：系统枚举（`包工包料`、`包工不包料`） |
| **工艺路线** | 单选下拉框 | 条件必填 | **数据来源**：基础数据工艺路线库。**仅当 `外协类型 = 工序外协` 时显示且必填**；选择后清空并重新加载工序选项 |
| **工序** | 多选下拉标签 | 条件必填 | **数据来源**：所选工艺路线下的工序节点列表。**仅当 `外协类型 = 工序外协` 时显示且必填**；支持多选 |
| **申请人** | 人员选择器 | 是 | **数据来源**：默认当前登录用户，支持切换申请人 |
| **申请日期** | 日期选择器 | 是 | **数据来源**：默认系统当天日期 |
| **需求日期** | 日期选择器 | 是 | **数据来源**：用户手动选择期望完成日期，不可早于申请日期；下推外协工单时自动带出且不可修改 |
| **所属公司** | 单选下拉框/只读 | 是 | **数据来源**：当前登录账套归属组织/法人实体 |
| **备注** | 多行文本 | 否 | **数据来源**：用户手动录入补充说明信息 |

> **注**：基本信息中**不设「优先级」字段**。

#### 3.3.2 物料清单（根据外协类型动态切换）
##### （1）操作按钮栏
+ **当 `外协类型 = 工序外协` 时**：
    - 提供按钮：**`从销售订单导入`**（原“从订单导入”统一改名为 **`从销售订单导入`**）、`从物料导入`、`删除选中`、`列配置`。
+ **当 `外协类型 = 整单外协` 时**：
    - 提供按钮：**`从销售订单导入`**、`删除选中`、`列配置`（**不展示** `从物料导入`）。

##### （2）表格列结构与数据来源对比
| 列名 | 工序外协是否展示 | 整单外协是否展示 | 数据来源与交互说明 |
| :--- | :---: | :---: | :--- |
| 选择框 + 销售订单号 | 是 | 是 | **数据来源**：来源于「从销售订单导入」弹窗所选行的销售订单号 `sourceOrderNo`（如从物料直接导入则为 `-`） |
| 项次（销售订单行） | 是 | 是 | **数据来源**：来源于所选销售订单行的项次 `lineNo` |
| 产品编码 | 是 | 是 | **数据来源**：来源于销售订单行关联的产成品编码 `productCode` |
| 产品名称 | 是 | 是 | **数据来源**：来源于销售订单行关联的产成品名称 `productName` |
| 产品分类 | 是 | 是 | **数据来源**：来源于产成品主数据所属分类 `productCategory` |
| 产品规格 | 是 | 是 | **数据来源**：来源于产成品主数据规格描述 `productSpec` |
| BOM版本 | 是 | 是 | **数据来源**：来源于产成品当前生效 BOM 版本 `bomVersion`，点击可预览 BOM |
| **物料编码** | **是** | **否（隐藏）** | **数据来源**：销售订单产品 BOM 展开后的待外协子件物料编码 `materialCode`（或物料库直接导入） |
| **物料名称** | **是** | **否（隐藏）** | **数据来源**：待外协子件物料名称 `materialName` |
| **物料分类** | **是** | **否（隐藏）** | **数据来源**：待外协子件物料分类 `materialCategory`（如机加件、钣金件） |
| **物料规格** | **是** | **否（隐藏）** | **数据来源**：待外协子件物料规格 `specification` |
| **单位** | **是（物料单位）** | **是（产品单位）** | **数据来源**：工序外协下取物料主数据计量单位；整单外协下取**产品的单位** |
| 当前库存 | 是 | 是 | **数据来源**：WMS 仓库实时可用库存量 `currentStock` |
| **申请数量（请购数量）** | **是（物料数量）** | **是（产品数量）** | **数据来源**：默认带出销售订单可外协数量（工序外协 = 产品数量 × 标准用量，整单外协 = 产品订单数量），支持手动修改 |
| 备注 | 是 | 是 | **数据来源**：用户手动输入的行备注 |
| 操作 | 是 | 是 | 单行删除按钮 |

#### 3.3.3 BOM 明细（仅 `整单外协` 展示）
+ **触发条件**：当 `外协类型 = 整单外协` 且物料清单中存在已导入产品行时，在物料清单卡片正下方展示 **BOM明细** 模块。
+ **联动机制**：点击上方物料清单中的任意产品行，下方 BOM 明细实时切换为该产品的子项物料列表；明细行的「需求数量」根据上方产品的「申请数量 × 标准用量」自动联动计算。
+ **BOM 明细列**：`子项物料编码`、`子项物料名称`、`物料分类`、`规格型号`、`单位`、`标准用量`、`需求数量`、`当前库存`、`备注`。

#### 3.3.4 导入弹窗规范
##### （1）「从销售订单导入」弹窗（含分页）
+ **弹窗结构**：支持按销售订单号、产品/物料名称或编码检索、表头单列筛选排序、右上角「合并相同产品/物料数量」开关与勾选导入。
+ **列宽规范**：弹窗表格中「**产品规格**」列的列宽与「**物料规格**」列的列宽保持一致（统一标准列宽，避免过宽挤压其他列），且支持表头拖拽调整列宽与超出省略悬浮提示。
+ **外协类型差异化展示**：
    - **工序外协模式**：列表包含销售订单号、项次、产品编码、产品名称、产品分类、产品规格、BOM版本、**物料编码、物料名称、物料分类、物料规格**、单位（物料单位）、数量（物料可外协数量）。
    - **整单外协模式**：列表**移除**物料编码、物料名称、物料分类、物料规格四列；展示销售订单号、项次、产品编码、产品名称、产品分类、产品规格、BOM版本、**单位（产品的单位）**、**数量（产品的数量）**。
+ **弹窗分页器规范**：
    - 弹窗底部左起展示 `已选中 X 条`；

#### 4.3.3 外协费用模块（新增 / 编辑页）
位于生产与 BOM 明细下方，采用**上方四列网格 + 下方费用说明**布局：
1. **合计价格**（只读输入框）：数据来源于上方生产明细所有行的 `含税总额` 自动汇总（$\sum \text{含税总额}$）。
2. **\* 优惠率(%)**（必填数值框 + 上下微调步进器）：默认 `0.00`，用户输入折扣比例（`0 ~ 100`）。
3. **\* 定金金额**（必填数值框 + 上下微调步进器）：默认 `0.00`，用户输入预付定金金额。
4. **右侧汇总展示区**：
   - `优惠金额`（红色文字）：自动计算 $\text{合计价格} \times (\text{优惠率} / 100)$
   - `优惠后金额`（蓝色 20px 加粗）：自动计算 $\text{合计价格} - \text{优惠金额}$
   - `待付金额`（灰色文字）：自动计算 $\max(0, \text{优惠后金额} - \text{定金金额})$
5. **费用说明**（多行文本域）：用户输入外协结算与费用补充说明。

### 4.4 外协工单详情页

+ **页签精简规则**：**外协工单详情页左侧五个页签下面的简介描述文字全部去掉**，仅保留序号与页签标题；支持左侧栏折叠收纳、点击页签平滑滚动定位右侧模块、右侧滚动自动高亮左侧页签。

#### 4.4.2 基本信息模块
+ 展示字段：`外协工单编码`、`外协申请单`、`外协方式`、`外协类型`、`计划开始日期`、`计划交货日期`、`需求日期`（位于供应商名称左侧）、`供应商名称`、`供应商联系人`、`联系电话`、`计划总台数`、`所属公司`、`工艺路线 & 外协工序`（工序外协展示）、`备注说明`。
+ 支持右上角 `收起 / 展开` 折叠，**不包含「优先级」字段**。

#### 4.4.3 生产明细与 BOM 明细模块
+ **生产明细**：根据当前工单的 `外协类型`（工序外协 vs 整单外协）动态展示对应列结构（整单外协隐藏物料编码、物料名称、物料分类、规格）。
+ **BOM 明细（仅 `整单外协` 展示）**：标题栏仅展示 `BOM明细` 标题，表格在「物料编码」左侧同步展示 **`销售订单`、`项次`、`产品编码`、`产品名称`、`产品规格`** 五列，底部支持分页，点击上方生产明细行可切换查看对应产品的 BOM 子项明细。

#### 4.4.4 外协费用明细模块（与新增页面样式同步，采用详情页展示信息样式）
+ **布局与新增页面同步**：在详情页「外协费用明细」模块中，采用与新增页面「外协费用」一致的四列排布结构：
    - 第一列：`合计价格`（展示 `¥X,XXX.XX`）
    - 第二列：`优惠率(%)`（展示 `0.00%`）
    - 第三列：`定金金额`（展示 `¥0.00`）
    - 第四列（右对齐汇总）：展示 `优惠金额：¥0.00`（红色）、`优惠后金额：¥X,XXX.XX`（蓝色大字号加粗）、`待付金额：¥X,XXX.XX`（灰色）
    - 底部区块：展示 `费用说明`
+ **详情页只读展示信息样式要求**：由于该页面为**详情页**，`合计价格`、`优惠率(%)`、`定金金额` 及 `费用说明` 的内容**全部采用详情页纯文字展示信息样式**（上方浅灰字段名 + 下方深色字段值），**不使用输入框或文本域边框样式**。

#### 4.4.5 生产进度与报工链接模块（外部供应商协同报工页规范）
详情页展示当前生产进度条、历史报工流水表，并提供供应商专属免登录 **「报工链接」**（支持一键复制链接或点击打开报工页面）。点击列表或详情页的 **「报工链接」** 打开报工页面后，遵循以下交互规范：

1. **手机页面与电脑页面兼容切换**：
   - 报工页面**右上角**提供 **「电脑端 / 手机端」** 视图切换按钮，支持电脑宽屏页面与手机竖屏页面的实时兼容切换。
2. **上方展示「基本信息」（支持折叠 + 字段精简与改名）**：
   - 位于报工页面最上方，卡片标题由“外协工单基本信息”改为 **「基本信息」**，右上角支持 `收起 / 展开` 折叠展示；
   - **删除三个字段**：删掉 **`外协工单号`**、**`关联外协申请单`**、**`供应商名称`** 这三个字段；
   - **字段改名**：原“工单备注”改为 **「备注」**；
   - 展示字段包括：`外协类型`、`外协方式`、`联系人`、`联系电话`、`计划开始日期`、`计划交货日期`、`需求日期`、`工艺路线`（工序外协）、`外协工序`（工序外协）、`计划总数量`、`所属公司`、`备注`。
3. **基本信息下方展示「生产明细」（支持折叠 + 支持分页）**：
   - 紧接在「基本信息」卡片正下方展示外协工单的 **「生产明细」** 卡片；
   - 右上角支持 `收起 / 展开` 折叠展示；
   - 表格底部**支持分页**（展示共 X 条、每页条数切换、页码切换）。
4. **当前生产进度与提交生产进度（整体数量更新 vs 进度更新）**：
   - **提交方式选择与锁定**：首次提交支持选择 **「数量更新（填写本次完成数量）」** 或 **「进度更新（调整提交后的整体进度）」**；第一笔生产进度提交成功后将自动锁定所选方式，后续不可切换。
   - **「数量更新」核心规则（对全部数量进行整体更新）**：
     * 选择「数量更新」时，**是对工单的全部计划总数量进行统一更新，而不是每一个物料分别去维护数量**；
     * 展示工单整体汇总行（名称、编码、计划总数量 `X PCS`）与**单一整体数量输入框**，下方实时显示 `本次生产数量合计：X PCS`；
     * 提交后按 $\text{累计完成总数量} / \text{计划总数量}$ 自动更新工单整体生产进度与「当前生产进度」卡片（展示 `X 整体数量 / 计划 Y PCS` 及 `剩余可报 Z PCS`）。
   - **「进度更新」核心规则**：
     * 通过 `0% ~ 100%` 滑块直接调整提交后的整体进度百分比，实时展示 `调整至整体进度：X%` 与 `本次新增进度：Y%`。
   - **公共提交项**：`提交人（必填）`、`联系电话`、`备注`（最多 500 字），点击底部「更新生产进度」按钮完成提报并写入历史提交记录。

#### 4.4.6 关联入库记录模块
+ **删除「新建入库单」按钮**：在详情页「关联入库记录」模块右上角，**移除「新建入库单」按钮**，仅作为入库记录只读查询看板。
+ **入库记录表格字段**：`入库单号`、`入库日期`、`收货仓库`、`有效入库数量`、`状态`、`操作人`。

## 5. 单据状态流转说明
### 5.1 外协申请单状态机
```plain
[草稿] ──(提交审核)──> [待审核]
[待审核] ──(审批通过)──> [进行中]
[待审核] ──(审批驳回)──> [审批驳回] ──(重新编辑提交)──> [待审核]
[进行中] ──(发起反审批)──> [待反审批] ──(反审批通过)──> [草稿]
[进行中] ──(全部申请数量已下推外协工单且完成)──> [已完成]
[草稿 / 待审核 / 进行中] ──(取消申请)──> [已取消]
```

### 5.2 外协工单状态机
```plain
[草稿] ──(提交审批)──> [审批中] ──(审批通过)──> [进行中]
[进行中] ──(供应商报工链接提交进度 < 100%)──> [进行中]（实时更新生产进度%）
[进行中] ──(供应商报工链接完成全部数量或进度达 100%)──> [待入库]
[进行中 / 待入库] ──(部分外协入库)──> [待入库]
[进行中 / 待入库] ──(累计入库数量 >= 计划数量，入库进度 100%)──> [已完成]
[草稿 / 进行中] ──(作废操作)──> [已作废]
```
