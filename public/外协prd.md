## 一、项目背景与业务目标

### 1.1 业务背景
在离散制造与装备制造场景中，企业常因产能瓶颈、特种工艺限制（如表面阳极氧化、真空热处理淬火、激光切割折弯）或整机 OEM 委外需求，将部分加工工序或整套产品委托外部供应商完成。通过建立标准化的 **「外协申请单 → 外协订单（外协工单） → 承包商报工 → 验收入库与财务核算」** 闭环流程，实现委外业务全链路透明化管控。

### 1.2 核心业务目标
1. **规范请购源头**：统一管理「工序外协」与「整单外协」两类委外请购需求，支持从销售订单快速穿透导入产品及下级 BOM 物料明细。
2. **打通单据上下游**：外协订单关联外协申请单，自动带出外协方式、外协类型、工艺路线、工序、需求日期及物料清单，实时追踪申请单「已转数/未转数」。
3. **精细化费用与税务核算**：支持按供应商自动匹配税率与发票类型，自动计算含税/未税单价、含税/未税金额、优惠金额、定金及应付金额。
4. **供应商协同与交期追踪**：通过生成「承包商安全报工链接」，赋能外部供应商在线汇报生产进度，并与厂内入库记录联动展示。

### 1.3 核心术语定义
| 术语名称 | 业务定义与说明 |
| :--- | :--- |
| **外协申请单** | 生产或计划部门发起的委外请购单据（单号前缀 `HYCG-`），用于明确需要委外加工的物料/产品、数量、工艺及需求交期。 |
| **外协订单（外协工单）** | 采购或外协跟单人员根据外协申请单或销售订单向指定供应商下达的正式委外执行单据（单号前缀 `WXGD-`）。 |
| **工序外协** | 仅将产品生产过程中的一道或多道特定工序（如 CNC 粗加工、表面阳极氧化、精密线割等）委外加工，标的物为具体子件物料。 |
| **整单外协** | 将整个成品或成套组件直接委托外部供应商生产交付，标的物为产成品本身，同时关联展示该产品的下级 BOM 明细。 |
| **包工包料** | 供应商负责提供原材料及加工服务，我方按约定总价或单价结算。 |
| **包工不包料** | 我方提供主要原材料/半成品（客供料），供应商仅负责加工制造并收取加工费。 |

## 二、整体业务流程与状态机

### 2.1 端到端业务主流程
```text
[销售订单] 
   │ (从订单导入产品/BOM物料)
   ▼
[外协申请单] ──(保存草稿 / 提交审核)──> [进行中]
   │                                       │
   │ (下推 / 关联拉取，自动带出类型、方式、工艺路线、工序、需求日期、物料明细)
   ▼                                       ▼
[外协订单(工单)] ──(绑定供应商、核算费用、提交审批)──> [进行中]
                                                       │
         ┌─────────────────────────────────────────────┴───────────────────────────┐
         ▼                                                                         ▼
[承包商安全链接在线报工] (实时更新生产进度%)                              [新建外协入库单] (更新入库进度%)
         │                                                                         │
         └─────────────────────────────────────────────┬───────────────────────────┘
                                                       ▼
                                                   [已完成]
```

### 2.2 「工序外协」与「整单外协」核心业务差异对比
| 维度 | 工序外协 | 整单外协 |
| :--- | :--- | :--- |
| **工艺路线与工序** | **必填**（单选工艺路线，多选该路线下的具体外协工序） | **不展示 / 无需填写** |
| **物料清单维度** | 展示产品信息列 + **物料明细列**（物料编码、物料名称、物料分类、规格） | 仅展示**产品信息列**（隐藏物料编码、物料名称、物料分类、规格 4 列） |
| **从订单导入逻辑** | 选择销售订单及产品后，进一步勾选展开的下级外协物料明细导入 | 选择销售订单后，直接勾选销售订单下的产品行整单导入 |
| **类型切换转换规则** | 由「整单外协」切为「工序外协」时，已导入产品行自动按 BOM 模板展开为下级物料行 | 由「工序外协」切为「整单外协」时，已导入物料行自动按「销售订单+项次+产品编码」合并为产品行 |
| **外协订单 BOM 明细** | 不展示底部独立「BOM明细」模块（可通过点击行内 BOM 版本弹窗查看） | 在「生产明细」卡片下方**固定展示「BOM明细」模块**，点击上方产品行联动切换对应 BOM |

## 三、模块一：外协申请单（Outsourcing Application）

### 3.1 外协申请单 - 列表页需求

#### 3.1.1 顶部状态页签与搜索栏
- **状态页签筛选**：`全部`、`草稿(N)`、`待审核(N)`、`进行中(N)`、`审批驳回(N)`、`已完成(N)`、`已取消(N)`（已移除“待反审批”状态）。除“全部”外，其余页签显示对应状态的实时单据数量。
- **关键词搜索**：支持按「申请单编号、物料编码、物料名称」模糊匹配搜索（支持回车触发及点击“搜索”按钮触发）。

#### 3.1.2 工具栏操作按钮
- **左侧主操作区**：
  - `新增`：跳转至「新增外协申请单」向导页。
  - `批量操作`：开启/关闭列表首列复选框多选模式。
  - `转外协工单`：勾选「进行中」的申请单后，批量将选中的外协申请单下推生成外协订单；当申请单全部转外协工单后，状态自动变为 `已完成`。
  - `自定义字段`：配置列表展示列。
  - `审批批次`：查看或处理批量审批任务。
- **右侧视图与表格工具**：
  - `单据视图 / 明细视图` 切换器。
  - `锁定列`、`展开/收起`、`字段配置` 快捷图标按钮。

#### 3.1.3 列表字段定义与行级操作（状态机与操作列按钮规则）
| 序号 | 字段名称 | 字段说明与交互规则 |
| :--- | :--- | :--- |
| 1 | **序号** | 默认显示行号；开启“批量操作”时显示复选框+行号 |
| 2 | **申请单编号** | 格式如 `HYCG-202610280001`，蓝色链接样式，点击进入「外协申请单详情页」 |
| 3 | **销售订单** | 支持展示多个关联销售订单及项次（如 `HY-26C-081 第3项、HY-26C-080 第1,2项`），支持拖拽调整列宽，超出列宽显示省略号，鼠标悬浮气泡展示完整内容 |
| 4 | **物料信息** | 支持展示多个物料/产品名称（顿号分隔），支持拖拽调整列宽，超出列宽显示省略号，鼠标悬浮气泡展示完整内容 |
| 5 | **申请日期** | 格式 `YYYY-MM-DD`，支持排序 |
| 6 | **总数量** | 当前申请单下所有物料行的请购数量之和，支持排序 |
| 7 | **已转外协数量** | 已关联生成外协订单的累计数量，支持排序 |
| 8 | **需求日期** | 期望交付日期，格式 `YYYY-MM-DD`，支持排序 |
| 9 | **备注** | 超长单行截断显示，悬浮提示完整内容 |
| 10 | **所属公司** | 支持表头筛选（如：智简工厂测试租户、华东精密智造分厂、深圳总装制造中心） |
| 11 | **状态** | 状态标签展示（进行中-蓝色、待审核-橙色、审批驳回-红色、已完成-绿色、草稿/已取消-灰色） |
| 12 | **操作** | - **`草稿`**：提供 `编辑 \| 删除 \| 提交审批`；点击「提交审批」后状态变为 `待审核`<br>- **`待审核`**：提供 `查看审核`；审核通过后状态变为 `进行中`，驳回则变为 `审批驳回`<br>- **`进行中`**：提供 `反审批`；点击「反审批」后状态退回 `草稿`；当全部数量转外协工单后状态自动变为 `已完成`<br>- **`审批驳回`**：提供 `编辑 \| 删除 \| 提交审批`（与草稿一致，点击「提交审批」后状态变为 `待审核`）<br>- **`已完成`**：显示 `-`<br>- **`已取消`**：显示 `-` |

### 3.2 外协申请单 - 新增/编辑向导页需求

#### 3.2.1 页面布局结构
- **顶部子标题栏**：展示「新增外协申请单 / 编辑外协申请单」、单据编号（如 `HYCG-202610270002`）、状态徽标（`草稿`）及右侧关闭按钮 `×`。
- **左侧步骤导航栏（支持折叠/展开）**：
  - 包含进度条及 2 个步骤锚点：`1. 基本信息`、`2. 物料清单`，点击可平滑滚动定位至对应卡片，右侧滚动时自动高亮当前步骤。
  - 底部实时统计卡片：`信息录入 (已填项/总项数)`、`必填项 (已填必填项/总必填项)`。
- **右侧主表单滚动区**：由「基本信息」卡片（支持展开/收起）和「物料清单」卡片组成。
- **底部固定操作栏**：左侧展示 `物料 N 项 · 基本信息`，右侧提供 `取消`、`保存`（存为草稿）、`提交审批`（状态更新为待审核）。

#### 3.2.2 Step 1：基本信息字段字典与校验规则（4列网格布局）
| 字段名称 | 控件类型 | 是否必填 | 默认值 / 选项 | 业务规则与联动逻辑 |
| :--- | :--- | :--- | :--- | :--- |
| **申请单编号** | 文本输入框 + 设置按钮 | 是 | 系统自动生成 `HYCG-YYYYMMDDXXXX` | 默认禁用只读，可点击右侧设置图标配置编号规则 |
| **外协方式** | 双项分段按钮 | 是 | 默认 `包工包料` | 选项：`包工包料`、`包工不包料`（位于外协类型左侧） |
| **外协类型** | 双项分段按钮 | 是 | 默认 `工序外协` | 选项：`工序外协`、`整单外协`；切换时动态控制下方工艺字段显隐及物料清单列结构 |
| **工艺路线** | 下拉单选框 | **工序外协必填** | 默认 `标准机加及表面处理工艺路线` | **仅当外协类型 = 工序外协时展示**；切换工艺路线时，自动过滤并重置右侧「工序」可选项 |
| **工序** | 多选下拉标签框 | **工序外协必填** | 默认选中当前路线首道工序 | **仅当外协类型 = 工序外协时展示**；支持多选、全选、清空及单个标签删除，至少需选一道工序 |
| **请购人** | 下拉单选框 | 是 | 默认当前登录人 | 选项示例：`测试`、`张工`、`李主管` |
| **申请日期** | 日期选择器 | 是 | 默认当日 `YYYY-MM-DD` | 必填校验 |
| **需求日期** | 日期选择器 | 否 | 空 | 选择期望完工交货日期 |
| **所属公司** | 下拉单选框 | 是 | 默认 `智简工厂测试租户` | 选项：`智简工厂测试租户`、`华东精密智造分厂`、`深圳总装制造中心` |

### 3.3 「从订单导入」弹窗需求（SalesOrderSelectModal）
点击「从订单导入」按钮弹出模态窗，支持最大化/还原，分上下两级联动结构：
1. **上半区：进行中的销售订单列表**
   - 搜索栏：支持按销售订单号、客户名称、产品名称或编码搜索，提供「查询」与「重置」按钮。
   - 列表字段：`复选框`、`销售订单号`、`客户名称`、`计划交期`、`包含产品摘要`、`产品项数`。
   - 交互：支持勾选单个或多个销售订单，下方区域实时联动加载所选销售订单的明细行。
2. **下半区：待导入明细列表（根据外协类型自适应）**
   - 当为 **工序外协** 时：展示「可导入的物料明细」，支持先按产品标签筛选（`全部产品` 或指定产品），再勾选需要外协的子件物料行（含来源销售订单、项次、产品编码/名称/分类/规格、BOM版本、物料编码/名称/分类/规格、单位、数量）。
   - 当为 **整单外协** 时：展示「可导入的产品明细」，直接勾选销售订单下的产成品行（不展开子件物料列）。
   - 右上角同样支持 `清空筛选`、`全选当前页` 及 `字段配置`。
3. **底部确认栏**：显示已选销售订单数与已选物料/产品项数，点击「确定导入 (N)」将数据追加至表单物料清单中。

### 3.4 外协申请单 - 详情页需求
- **顶部概览横幅（Banner）**：
  - 展示返回按钮、申请单编号（如 `HYCG-202610280001`）、状态标签、外协方式标签（`包工包料 / 包工不包料`）、外协类型标签（`工序外协 / 整单外协`）。
  - 次行展示：`请购人` · `申请日期` · `需求日期`。
  - *注：顶部横幅保持精简，不重复展示优先级与所属公司。*
- **详情页双页签切换**：
  1. **页签一：`单据信息与物料清单 (N)`**
     - **基本信息卡片（5列网格布局，支持收起/展开）**：依次展示 `申请单编码`、`外协方式`、`外协类型`、`请购人`、`申请日期`、`需求日期`、`所属公司`、`联系人`、`单据状态`；若为工序外协，额外展示 `工艺路线` 与 `工序`（占2列）；最后展示 `备注`（占2列）。
     - **物料清单卡片**：支持表头每列独立搜索/筛选/排序及右上角「字段配置」。相比新增页，新增 **`序号`** 列（默认左固定）和 **`已转数/未转数`** 列（格式如 `8/0`，已转数蓝色显示、未转数橙色显示），`请购数量` 采用标准正文字体颜色展示。
  2. **页签二：`关联外协工单 (N)`**
     - 列表展示由当前外协申请单下推或关联生成的全部外协工单，包含字段：`外协工单号`、`产品名称`、`供应商名称`、`外协方式`、`外协类型`、`计划数量`、`生产进度`、`入库进度`、`计划交期`、`状态`。

## 四、模块二：外协订单 / 外协工单（Outsourcing Order）

### 4.1 外协订单 - 列表页需求

#### 4.1.1 状态页签与搜索栏
- **状态页签**：`全部`、`草稿(N)`、`审批中(N)`、`进行中(N)`、`待入库(N)`、`已完成(N)`、`已作废(N)`。

### 4.2 外协订单 - 新增/编辑向导页需求

#### 4.2.1 整体布局与三步导航
- **左侧步骤导航栏（支持折叠/展开）**：
  - `1. 基础信息`（外协类型、外协申请单、供应商与计划日期）
  - `2. 生产明细`（BOM 物料、规格、单位、计划数量与单价税率）
  - `3. 外协费用`（按计价方式核算外协费用、优惠率、定金与税费）
  - 底部展示 `信息录入` 与 `必填项` 统计卡片。

#### 4.2.2 Step 1：基础信息字段字典与强联动规则（4列网格布局）
| 字段名称 | 控件类型 | 是否必填 | 业务规则与上下游强联动逻辑 |
| :--- | :--- | :--- | :--- |
| **外协工单编码** | 文本输入框 + 设置按钮 | 是 | 系统自动生成 `WXGD-YYYYMMDDXXXX`，只读 |
| **外协申请单** | 弹窗选择器（选填） | 否 | 位于外协工单编码右侧；点击输入框或搜索图标打开「选择外协申请单」弹窗（样式与从销售订单导入弹窗一致，列表展示外协申请单列表页除操作列外的全部字段：`序号`、`申请单编号`、`销售订单`、`物料信息`、`申请日期`、`总数量`、`已转外协数量`、`需求日期`、`备注`、`所属公司`、`状态`，支持表头搜索/筛选/排序、列宽拖拽及字段配置）。**选中外协申请单后自动执行以下联动**：<br>1. 自动带出并锁定 `外协类型`；<br>2. 自动带出 `外协方式`；<br>3. 若为工序外协，自动带出并锁定 `工艺路线` 与 `工序`；<br>4. 自动带出并锁定 `需求日期`；<br>5. 自动将该申请单下的物料清单载入下方「生产明细」表格中。<br>**未选择或清空外协申请单时**：`外协类型`、`工艺路线`、`工序`、`需求日期` 均可由用户自行选择。 |
| **外协类型** | 双项分段按钮 | 是 | 选项：`工序外协`、`整单外协`。未选择外协申请单时可自由切换；已选择外协申请单时由申请单自动带出并置灰锁定。 |
| **外协方式** | 双项分段按钮 | 是 | 选项：`包工包料`、`包工不包料` |
| **工艺路线** | 下拉单选框 | **工序外协必填** | **仅工序外协展示**；未选择外协申请单时可自由下拉选择；已选择外协申请单时由申请单带出并锁定只读 |
| **工序** | 多选下拉标签框 | **工序外协必填** | **仅工序外协展示**；未选择外协申请单时可自由多选工序；已选择外协申请单时由申请单带出并锁定只读 |
| **需求日期** | 日期选择器 | 否 | 位于供应商左侧；未选择外协申请单时可自由选择日期；已选择外协申请单时由申请单自动带出且锁定只读 |
| **供应商** | 搜索下拉选择框 + 新增按钮 | 是 | 支持按供应商名称或编码搜索（下拉项展示税率，如 `东莞市安可精密机械有限公司 SU-00006 (13%)`）。**选中供应商后自动联动**：<br>1. 自动填充 `联系人` 与 `联系电话`；<br>2. 自动更新全局 `税率`（如 13% 或 3%）及发票 `税别`，并重算生产明细中所有行的未税单价与未税金额。 |
| **联系人** | 文本输入框 | 否 | 选定供应商后自动带出，支持手动微调（未选供应商时禁用） |
| **联系电话** | 文本输入框 | 否 | 选定供应商后自动带出，支持手动微调（未选供应商时禁用） |
| **计划日期** | 起止日期组合框 | 是 | 包含 `开始日期` 至 `交期日期` |
| **所属公司** | 下拉单选框 | 是 | 选项：`智简工厂测试租户`、`华东精密智造分厂`、`深圳总装制造中心` |
| **备注** | 多行文本框 | 否 | 独占一行，填写外协工单备注说明 |

#### 4.2.3 Step 2：生产明细与 BOM 明细联动规则
1. **生产明细表格（支持表头搜索/筛选/排序、从销售订单导入、删除选中、字段配置）**
   - **字段列表（共 20 列）**：
     - 通用列（16列）：`销售订单号`（含行勾选框）、`项次`、`产品编码`、`产品名称`、`产品分类`、`产品规格`、`BOM版本`（蓝色链接，点击弹窗查看该物料 BOM 结构）、`单位`、`当前库存`、`*计划数量`（可编辑数字框）、`未税单价`（自动计算）、`*含税单价`（可编辑输入框）、`税率`（由供应商带出）、`含税金额`（自动计算）、`未税金额`（自动计算）、`备注`（可编辑输入框）+ 右侧固定 `操作（删除）` 列。
     - 工序外协专属列（4列）：`物料编码`、`物料名称`、`物料分类`、`规格`（当外协类型为「整单外协」时自动隐藏此 4 列）。
   - **行级价格实时计算公式**：
     - $\text{未税单价} = \frac{\text{含税单价}}{1 + \text{供应商税率}}$
     - $\text{含税金额} = \text{计划数量} \times \text{含税单价}$
     - $\text{未税金额} = \text{计划数量} \times \text{未税单价}$
   - **表格底部汇总与分页栏**：左侧实时汇总显示 `含税金额：XX.XX` 与 `未税金额：XX.XX`，右侧为标准分页器。

2. **BOM 明细子模块（仅当外协类型 = 整单外协时展示）**
   - 位于「生产明细」卡片下半部分，支持展示生产明细中对应产品的子件 BOM 清单（点击上方任意产品行可筛选或切换对应产品的 BOM 明细）。
   - **支持列（共 23 列，支持表头筛选排序与字段配置）**：`序号`、`销售订单`、`项次`、`产品编码`、`产品名称`、`产品规格`、`物料编码`、`物料名称`、`物料分类`、`规格`、`图号`、`BOM版本`、`单位`、`标准用量`、`品牌`、`材质`、`标准成本`、`工艺路线`、`损耗率`、`生产/采购方式`、`物料图片`、`物料二维码`、`备注`。

#### 4.2.4 Step 3：外协费用核算规则
- **字段构成与联动公式**：
  1. `合计价格`（只读）：自动取自上方生产明细的「含税金额」总计。
  2. `*优惠率(%)`（可编辑数字步进框，范围 `0.00 ~ 100.00`）：输入优惠折扣百分比。
  3. `*定金金额`（可编辑数字步进框，默认 `0.00`）：输入预付定金金额。
  4. `优惠金额`（自动计算）：$\text{优惠金额} = \text{合计价格} \times \frac{\text{优惠率}}{100}$
  5. `优惠后金额`（自动计算）：$\text{优惠后金额} = \max(0, \text{合计价格} - \text{优惠金额})$
  6. `应付金额`（自动计算高亮展示）：$\text{应付金额} = \max(0, \text{优惠后金额} - \text{定金金额})$
  7. `费用说明`（多行文本框）：填写加工工艺计费说明或补充条款。

### 4.3 外协订单 - 详情页需求（四页签结构）

#### 4.3.1 顶部概览横幅（Banner）
- **第一行**：返回按钮、外协工单号（如 `WXGD-202610280001`）、状态徽标、外协方式徽标（`包工包料`）、外协类型徽标（`工序外协`）。

#### 4.3.2 页签一：`工单信息与物料明细`
1. **基本信息卡片（5列网格布局，支持收起/展开）**：
   - 字段顺序：`外协工单编码`、`外协申请单`、`外协方式`、`外协类型`、`计划开始日期`、`计划交货日期`、`需求日期`、`供应商名称(含编码)`、`供应商联系人`、`联系电话`、`计划总台数`、`所属公司`。
   - 若为 `工序外协`：展示 `工艺路线`、`外协工序`（占2列）。
   - 最后展示：`备注说明`（占2列）。
2. **生产明细卡片**：
   - 支持每列表头独立搜索/筛选/排序及右上角「字段配置」（含上下移动、拖拽、左右置顶固定）。
   - 整单外协自动隐藏物料专属 4 列（`物料编码`、`物料名称`、`物料分类`、`规格`）。
3. **BOM 明细卡片（仅整单外协展示）**：
   - 位于生产明细下方，支持点击上方产品行切换对应产品的 BOM 明细，具备完整的表头筛选、排序、字段配置与分页功能。

#### 4.3.3 页签二：`外协费用明细`
- 采用 6 列网格表单展示财务核算数据：
  - 第一行：`计费总数量`、`税别`（如增值税专用发票）、`税率`（如 `13%`）
  - 第二行：`未税总金额`、`预计税额`、`含税总金额`（蓝色加粗高亮）
  - 第三行：`费用说明`（跨 5 列展示）

#### 4.3.4 页签三：`生产进度与报工链接 (N)`
1. **生产进度概览条**：展示当前整体生产进度百分比（`0% ~ 100%`）、可视化进度条、计划开始日期与计划交期。
2. **承包商报工链接卡片**：
   - 显示链接有效状态徽标（`链接有效` / `已停用`）。
   - 展示加密访问 URL（如 `https://supercodezj.com/zjgc/#/outsourcing-report?token=...`）。
   - 提供 4 个操作按钮：`复制链接`（写入剪贴板并 Toast 提示）、`打开页面`、`重置链接`（重新生成随机 Token 并激活链接）、`停用 / 启用`（切换链接可用状态）。
   - 底部展示元数据：`报工方式（进度更新）`、`生成时间`、`最近访问时间`。
3. **生产进度记录表格**：
   - 按时间倒序或正序记录供应商每次报工明细，包含字段：`提交时间`、`报工方式`、`本次报工`（如 `新增 35%`）、`提交前`、`提交后`、`提交人`、`备注`。

#### 4.3.5 页签四：`入库记录 (N)`
- **顶部说明与操作**：展示累计有效入库数量与入库进度（如 `当前入库 3 / 12 件（入库进度 25%）`），右上角提供 `新建入库单` 按钮。
- **关联入库记录表格**：展示字段包括 `入库单号`（如 `WXRK-20261028001`）、`入库日期`、`入库仓库`、`入库数量`、`入库进度`（进度条+百分比）、`状态`（`已入库`）、`入库人`。

## 五、非功能性需求与通用交互规范

### 5.1 视觉与容器规范
1. **底色与卡片区分**：所有新增页、编辑页与详情页均采用统一的浅灰底色（`#f4f6f9`）搭配纯白内容卡片（`#ffffff`），卡片内部表单区域禁止出现异色底块，统一通过 `1px` 浅灰描边（`border-slate-200/80`）与微阴影区分层级。
2. **只读与禁用态反馈**：由上游单据带出且不可修改的字段（如外协订单中的需求日期、关联申请单后的外协类型与工艺工序）采用浅灰背景（`bg-slate-50/80`）与禁用光标（`cursor-not-allowed`）。

### 5.2 表格通用能力规范
1. **表头交互**：支持点击放大镜图标弹出文本搜索框、点击漏斗图标弹出枚举值单选筛选菜单、点击上下三角图标切换 `升序 / 降序 / 默认` 排序。
2. **字段配置持久化体验**：所有明细表格右上角均提供「字段配置」弹窗，支持全选、清空、显隐勾选、拖拽排序、上下微调、左右固定列及一键重置为默认列配置。
3. **横向拖拽滚动**：宽表格容器支持鼠标按住空白处左右拖拽平滑滚动，保障多列场景下的查阅效率。
